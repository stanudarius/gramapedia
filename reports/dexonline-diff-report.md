1. **«așază»** vs **«așează»**
   - Categorie: Ortografie
   - Notă: Conform DOOM3, verbul «a așeza» are la indicativ prezent persoana a III-a singular și plural forma «așază» (cu «a», nu «ea»).

2. **«voiam»** vs **«vroiam»**
   - Categorie: Morfologie
   - Notă: Forma «vroiam» este o contaminare hibridă incorectă între verbele «a vrea» (imperfect: «vream») și «a voi» (imperfect: «voiam»). Norma literară recomandă «voiam» sau «vream».

3. **«mi-ar plăcea»** vs **«mi-ar place»**
   - Categorie: Morfologie
   - Notă: Condițional-optativul prezent se construiește cu infinitivul verbului («plăcea»), nu cu indicativul prezent («place»). Așadar, forma corectă este «mi-ar plăcea».

4. **«în continuu / încontinuu»** vs **«încontinuu (adverb)»**
   - Categorie: Ortografie
   - Notă: Adverbul cu sensul de «mereu, neîncetat» se scrie legat («Vorbește încontinuu»), în timp ce prepoziția «în» urmată de adjectivul «continuu» se scrie separat («Este într-un proces continuu»).

5. **«de mult / demult»** vs **«demult (prepoziție + adjectiv)»**
   - Categorie: Ortografie
   - Notă: Adverbul cu sensul de «odinioară, în trecut» se scrie legat («A fost odată demult»), iar când indică o durată mare sau cantitate se scrie separat («Nu ne-am văzut de mult timp»).

6. **«chibrituri»** vs **«chibrite»**
   - Categorie: Morfologie
   - Notă: Forma corectă de plural pentru substantivul neutru «chibrit» este «chibrituri» conform DOOM3.

7. **«remunera»** vs **«renumera»**
   - Categorie: Lexicosemantică
   - Notă: Verbul cu sensul de a plăti pentru o muncă efectuată este «a remunera» (din latinescul remunerari). «A renumera» înseamnă a număra din nou.

   - Notă: Forma corectă este «genuflexiune» (cu «u»), provenită din latinescul «genu» (genunchi) și «flectere» (a îndoi).
